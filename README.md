# Irfan & Sharafina Engagement Website

## Website behaviour
- `index.html` displays the supplied invitation opener artwork.
- Tapping **Tap to Open** starts the instrumental and opens the actual Canva invitation in a new browser tab:
  https://sharaxirfanengagement.my.canva.site/engagement-invitation-2026
- The music control on the opener lets visitors pause or resume the instrumental.

## Publish on GitHub Pages
1. Upload `index.html`, `README.md`, and the complete `assets` folder to the root of the repository's `main` branch.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.
5. Your site will be published at `https://YOUR-USERNAME.github.io/`.

## Music limitation
Browsers block autoplay until a visitor interacts with the page. The first tap starts the music. The Canva invitation opens in a separate tab so the opener tab can remain available. Whether audio continues while the visitor views another tab depends on the browser and device. The Canva page is hosted separately, so this GitHub page cannot force music to play inside the Canva page itself.
